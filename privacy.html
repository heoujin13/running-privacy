Running Master 개인정보 처리방침

시행일: 2026년 10월 2일

Running Master(이하 "앱")는 러닝 기록과 목표 페이스 코칭을 위해 휴대폰의 위치 정보를 사용합니다. 앱은 개발자가 운영하는 서버가 없으며, 사용자의 개인정보를 개발자에게 전송하거나 수집하지 않습니다.

1. 기기 안에서만 처리하는 정보

  • 위치 정보(GPS): 달린 거리, 페이스, 속도, 경로를 계산하기 위해 러닝 중에만 사용합니다.
  • 러닝 기록: 날짜, 거리, 시간, 페이스, 칼로리, 랩, 경로를 휴대폰의 앱 저장소에 저장합니다.
  • 설정 값: 목표 페이스, 체중(칼로리 계산용), 월간 목표 등을 휴대폰에 저장합니다.

위 정보는 휴대폰 밖으로 전송되지 않습니다. 사용자가 직접 '백업 파일 내려받기'를 한 경우에만 사용자가 선택한 위치에 파일이 저장됩니다.

2. 외부로 전송되는 정보

지도 배경 이미지를 표시할 때 지도 이미지 제공 서버(OpenStreetMap, tile.openstreetmap.org)에 이미지를 요청합니다. 이 과정에서 일반적인 인터넷 통신과 같이 기기의 IP 주소와 화면에 보이는 지도 영역이 해당 서버에 전달될 수 있습니다. 앱 설정 → 데이터 절약 → 지도 배경 이미지를 '항상 끄기'로 바꾸면 이 요청을 하지 않습니다.

그 밖에 광고, 분석 도구, 로그인, 결제 기능은 없으며 제3자에게 정보를 제공하지 않습니다.

3. 앱이 사용하는 권한

  • 위치: 러닝 거리·페이스 계산. "앱 사용 중에만 허용"으로 충분합니다.
  • 알림: 러닝 중 알림창에 "기록 중"을 표시합니다. 이 알림이 있는 동안에는 화면을 꺼도 기록과 진동 코치가 계속 동작합니다.
  • 진동: 목표 페이스에서 벗어났을 때 알려 줍니다.
  • 인터넷: 지도 배경 이미지를 받을 때만 사용합니다.

4. 보관 기간과 삭제

러닝 기록은 사용자가 삭제할 때까지 휴대폰에 보관됩니다. 기록 화면에서 개별 기록을 삭제하거나, 설정 → 데이터 → 모든 기록 삭제, 또는 앱을 삭제하면 모든 정보가 지워집니다.

5. 만 14세 미만 아동

앱은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.
